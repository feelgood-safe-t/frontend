# 청노 Frontend

**청노(청산노노)**는 시장 정보와 뉴스로 상승·하락을 판단하고, 판단 과정에 대한 피드백을 받는 교육용 시뮬레이션입니다.

- 투자 성향 설문 10문항 → AI 성향 분석·문항 선택 → 순차 3문항(각 최대 3분)
- 60배속 차트·뉴스, 반복 판단·확신도·근거·뉴스 읽음 기록
- 최종 7항목 점수·개선점·PASS 결과와 누적 평가 기록

## 실행

```bash
npm install
npm run dev
```

API 주소가 없으면 데모로 실행됩니다. 실제 연동은 `.env.development.local`에 아래 값을 설정하고 개발 서버를 재시작합니다.

```dotenv
VITE_SAFE_T_API_BASE_URL=http://47.129.245.75:8000
```

프로덕션 빌드도 `.env.production`에 설정된 같은 공개 테스트 API를 사용합니다.
S3 정적 웹사이트 엔드포인트를 HTTP로 열면 바로 연동할 수 있습니다. CloudFront
등으로 프론트를 HTTPS로 제공할 때는 혼합 콘텐츠 차단을 피하도록 백엔드도
HTTPS 주소를 사용해야 합니다.

최신 백엔드 `0.7`의 API 세 개만 사용하며 로그인·참가자 헤더·서버 세션은 없습니다.

| API                                  | 용도                                            |
| ------------------------------------ | ----------------------------------------------- |
| `GET /v1/poc/questionnaire`          | 설문 조회                                       |
| `POST /v1/poc/onboarding-assessment` | 설문 분석과 세 문항의 차트·뉴스 수신            |
| `POST /v1/poc/evaluation`            | 설문·최종 판단/열람 묶음 제출 및 평가 결과 수신 |

타이머, 순차 진행, 전역 이벤트 순서는 프론트에서 관리합니다. 진행 상태는 메모리에만 유지되므로 새로고침하면 다시 시작합니다. 종료 기록과 수신한 평가 결과는 로컬 저장소에 보관하며 기존 기록도 유지합니다. 서버에는 진행·결과를 저장하지 않습니다.

AI 분석·채점은 시간이 걸릴 수 있어 대기 상태를 표시합니다. 실패하면 오류와 재시도를 제공하며 데모·고정 문항·임의 점수로 전환하지 않습니다. 재요청은 서버에서 새 평가를 수행하므로 비용이 다시 발생하거나 분석 결과가 달라질 수 있습니다. 결과는 방향 적중률이나 수익률 점수가 아닙니다.

백엔드 실행에는 서버 전용 `OPENAI_API_KEY`, `OPENAI_MODEL`, `OPENAI_REASONING_EFFORT` 설정이 필요합니다. 백엔드 폴더에서 `.env.example`을 참고해 `.env`를 준비한 뒤 `uv sync`, `uv run --env-file .env safe-t-server`로 실행하세요. CORS에는 프론트 주소를 허용해야 합니다. **OpenAI 키를 `VITE_` 환경변수나 프론트 코드에 넣지 마세요.**

현재 백엔드의 `participantSafe=false` 자료는 로컬 개발 확인용입니다. 개발 화면에서만 검수 전 자료를 허용하며, 프로덕션 빌드는 가명화·정규화·공개 적합 상태가 모두 확인된 자료만 표시합니다. 공개 배포 전 데이터 검수를 완료해야 합니다. PASS는 교육용 평가 결과이며 공인 자격이나 서버에서 검증 가능한 인증서가 아닙니다.

## 검증

```bash
npm test
npm run lint
npm run build
npm run test:integration
```

통합 검증은 형제 폴더의 최신 `backend`와 해당 의존성이 설치된 `backend/.venv/bin/python`을 사용합니다. 다른 가상환경은 `SAFE_T_TEST_PYTHON=/절대/경로/python npm run test:integration`으로 지정할 수 있습니다.

실제 FastAPI·Snapshot 검증·점수 합산 규칙을 별도 임시 포트에서 실행하고, **테스트에서만** LLM 응답을 대체합니다. OpenAI 호출·DB 생성 없이 3문항 완주, 반복 판단·열람, 시간 만료·조기 종료, 최종 평가와 기록 보존을 검증합니다. 기존 개발 서버는 변경하지 않으며 테스트 서버는 종료 시 정리됩니다.

## S3 정적 배포

```bash
npm run build
aws s3 sync dist/ s3://버킷이름/ --delete
```

버킷 루트의 `index.html`을 시작 문서로 설정합니다. 빌드 자산은 `/assets/`를
기준으로 생성되며 라우팅은 해시 방식이므로 별도의 SPA 경로 재작성은 필요하지
않습니다. 실제 S3 도메인이 확정되면 `index.html`의 OG 이미지 경로를 절대
URL로 바꾸는 것이 좋습니다.
