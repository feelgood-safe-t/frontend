# 청노 Frontend

**청노**는 **청산노노**의 줄임말로, 시장 정보를 읽고 상승·하락 판단과 근거를 기록하는 교육용 시뮬레이션입니다. 로고 적용 전까지 헤더에는 청노 텍스트를 표시합니다.

- 투자 성향 설문 10문항 → 평가 안내 → 순차 3문항(각 최대 3분)
- 60배속 가격·뉴스 공개, 반복 판단·확신도·근거 태그와 뉴스 상세 열람 기록
- 문항 완료·시간 만료·시험 종료, 새로고침 후 진행 복구, 누적 기록
- 7항목 평가 기준과 별도의 샘플 보고서·인증서

```bash
npm install
npm run dev
```

API 주소를 지정하지 않으면 **데모**로 실행됩니다. 로컬 연동은 `.env.development.local`에 다음을 설정한 뒤 개발 서버를 재시작합니다. 이 파일은 Git에 포함되지 않으며 프로덕션 빌드에는 적용되지 않습니다.

```dotenv
VITE_SAFE_T_API_BASE_URL=http://localhost:8000
```

백엔드를 `SAFE_T_DEVELOPMENT_NO_AUTH=true`로 실행하고 CORS에 `http://localhost:3000`을 허용하면 로그인 없이 연결됩니다. guest가 발급한 참가자 ID를 `X-Participant-Id` 헤더로 보내며, 토큰이 없는 경우 `Authorization` 헤더는 보내지 않습니다. 기존 인증 모드에서 토큰이 발급되면 Bearer도 함께 보냅니다. 무인증 모드는 로컬 개발용입니다.

같은 API 주소에서 인증 모드를 바꾸거나 개발 DB를 교체했다면 화면의 리셋 버튼을 누른 뒤 다시 시작합니다.

게스트 발급 → 현재 설문 → 설문 제출 → 세션 생성·시작 → 판단·열람 → 완료·종료 API를 사용합니다. 실패 시 데모로 전환하지 않으며 미확인 요청은 같은 키로 재시도합니다. 참가자·진행 정보는 세션 저장소, 종료 기록은 로컬 저장소에 보관합니다. 새로고침은 복구되지만 탭을 닫거나 저장 데이터를 지우면 진행 정보가 사라질 수 있습니다. 리셋은 화면의 저장 정보만 지우며 서버 기록은 삭제하지 않습니다.

현재 백엔드에는 참가자용 점수·보고서 API가 없어 실제 평가는 **제출 기록만 표시**합니다. `ENDED`와 `SNAPSHOT_READY` 모두 종료 기록으로 복구하며, 스냅샷 준비를 채점 완료로 표시하지 않습니다. 저장 결과가 미확인인 요청은 종료 후에도 같은 키로 재시도하고, 확인 전에는 새 평가를 시작할 수 없습니다. 방향 정답이나 임의 점수를 계산하지 않습니다. 이전 버전 기록은 원본을 보존하며 현재 점수와 비교하지 않습니다.

원천 시나리오는 개발 서버에서만 확인할 수 있습니다. 프로덕션 빌드는 가명화·정규화·공개 적합 상태가 모두 확인된 자료만 표시합니다. 이 화면 방어와 별개로, 공개 API 역시 안전한 자료만 전달하도록 백엔드 준비가 필요합니다. 관리자·LLM 비밀 키는 프론트 환경 변수에 넣지 않습니다.

```bash
npm test
npm run lint
npm run build
```

`npm run test:integration`은 실제 백엔드 API로 3문항 완주, 반복 판단·뉴스 열람 저장, 조기 종료, 시간 만료, 응답 유실·재시도와 스냅샷 생성 후 기록 복구를 검증합니다. 같은 상위 폴더의 `backend`와 설치된 `backend/.venv`가 필요합니다. 임시 DB와 별도 8001 서버를 자동 생성·정리하며, 실행 중인 8000 개발 서버와 기존 기록은 건드리지 않습니다.

GitHub Pages 경로는 `/frontend/`, 라우팅은 해시 방식입니다.
