# SAFE:T Frontend

금융시장 정보를 확인하고 **상승/하락 판단과 근거를 기록하는 위험 대응 시뮬레이션** 프론트엔드입니다.

## 주요 기능

- 투자 성향 온보딩 설문 10문항과 Mock 시나리오 매칭
- 3개 자산 시나리오 자유 이동
- 상승/하락 선택 및 판단 근거 입력
- 전체 6분 제한 시간과 자동 종료
- OMR 답안 확인 및 평가 결과 제공
- 누적 평가 이력 LocalStorage 저장 및 결과별 검증 코드 확인

현재는 목업 데이터와 브라우저 상태를 사용하며, 백엔드 API 연동은 추후 진행할 예정입니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 확인 명령어

```bash
npm run lint
npm run build
```
