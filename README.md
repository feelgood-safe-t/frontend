# SAFE:T Frontend

시장 정보를 읽고 상승·하락 판단과 근거를 기록하는 교육용 시뮬레이션입니다.

- 투자 성향 설문 10문항 → 평가 안내 → 순차 3문항(각 최대 3분)
- 60배속 가격·뉴스 공개, 반복 판단·확신도·근거 태그와 뉴스 상세 열람 기록
- 문항 완료·시간 만료·시험 종료, 새로고침 후 진행 복구, 누적 기록
- 7항목 평가 기준과 별도의 샘플 보고서·인증서

```bash
npm install
npm run dev
```

API 주소를 지정하지 않으면 **데모**로 실행됩니다. 실제 연동은 `.env.local`에 다음을 설정한 뒤 개발 서버를 재시작합니다.

```dotenv
VITE_SAFE_T_API_BASE_URL=http://localhost:8000
```

게스트 발급 → 현재 설문 → 설문 제출 → 세션 생성·시작 → 판단·열람 → 완료·종료 API를 사용합니다. 실패 시 데모로 전환하지 않으며 미확인 요청은 같은 키로 재시도합니다. 서버에서 프론트 주소의 CORS 허용이 필요합니다. 토큰은 세션 저장소, 종료 기록은 로컬 저장소에 보관합니다. 새로고침은 복구되지만 탭을 닫거나 저장 데이터를 지우면 진행 정보가 사라질 수 있습니다. 리셋은 화면의 저장 정보만 지우며 서버 기록은 삭제하지 않습니다.

현재 백엔드에는 참가자용 점수·보고서 API가 없어 실제 평가는 **제출 기록만 표시**합니다. 방향 정답이나 임의 점수를 계산하지 않습니다. 이전 버전 기록은 원본을 보존하며 현재 점수와 비교하지 않습니다.

원천 시나리오는 개발 서버에서만 확인할 수 있습니다. 프로덕션 빌드는 가명화·정규화·공개 적합 상태가 모두 확인된 자료만 표시합니다. 이 화면 방어와 별개로, 공개 API 역시 안전한 자료만 전달하도록 백엔드 준비가 필요합니다. 관리자·LLM 비밀 키는 프론트 환경 변수에 넣지 않습니다.

```bash
npm test
npm run lint
npm run build
```

격리된 테스트 DB로 실행한 로컬 백엔드가 있으면 `SAFE_T_TEST_API_URL=http://127.0.0.1:8001 node --import tsx tests/api-smoke.ts`로 실제 제출·복구 흐름을 검증할 수 있습니다. 이 명령은 지정한 서버에 테스트 평가를 생성합니다.

GitHub Pages 경로는 `/frontend/`, 라우팅은 해시 방식입니다.
